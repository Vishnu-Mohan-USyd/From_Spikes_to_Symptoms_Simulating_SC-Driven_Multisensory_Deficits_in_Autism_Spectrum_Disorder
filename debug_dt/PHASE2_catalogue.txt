ANALYSIS — which paths can produce dt-dependence?
================================================

For each I_M / I_M_inh injection, the question is: does the per-substep
contribution INTEGRATED over many substeps depend on dt?

1) SPIKE-DRIVEN source onto leaky-integrator I_M:
   Pattern: I_M += spike_kick * S[t] where S[t] is sparse binary.
   Steady-state mean contribution = spike_kick * (rate * dt) / (dt/tau_syn)
                                  = spike_kick * rate * tau_syn  <- DT-INVARIANT
   So spike-driven I_M injections are dt-invariant in mean.

   BUT — peak/burst statistics differ:
   - Single spike kick on I_M = full spike_kick magnitude in 1 substep.
   - voltage update: dv = dt * (... + I_M)
   - So single-spike instantaneous v-jolt = dt * spike_kick  <- DT-DEPENDENT
   This affects spike-threshold dynamics in finely-stochastic ways but not
   integrated mean.

2) CONTINUOUS source onto leaky-integrator I_M (Form 2 corrected):
   Pattern: I_M += I_nmda * (1 - exp(-dt/tau_syn))
   Steady-state: I_M = I_nmda * (1-exp(-dt/tau)) / (1-(1-dt/tau)) ≈ I_nmda
   <- DT-INVARIANT for steady-state regime.
   In brief-transient regime (event < tau_nmda), nmda_m underfills (~12% at dt=0.05
   vs dt=0.1 per task #10 analysis).  SBW uses 200 ms stim ≫ tau_nmda=40 ms, so
   steady-state regime, NOT transient.

3) LATERAL INHIBITION (L2249, L2211, L2214) — uses CURRENT-substep spike, not
   delayed buffer.  At smaller dt, MSI spike rate per substep is smaller, but
   the integrated effect on the leaky-integrator I_M should still be dt-invariant.

CANDIDATE DT-DEPENDENT ARTIFACTS (potential bugs to test):

A) AGC update with alpha_fast=1e-3 NOT scaled by dt.  Same update once per
   external frame.  If equilibrium values of exc/inh differ at finer dt
   (even slightly), AGC drifts to a different g_FFinh.  H_agc.

B) Lateral inh uses I_latM = mm(new_sM, W_MSI_inh) where new_sM is CURRENT-
   substep spike.  At dt=0.05, fewer spikes per substep on average, so
   per-substep magnitude of I_latM is smaller (sparser).  Integrated effect
   should still match, but check.

C) ampa_m (line 2054-2055):
   ampa_m += ampa_alpha * (I_M_a_AMPA + I_M_v_AMPA).clamp(min=0)
   - source is spike-driven, dt-invariant mean
   - but the clamp(min=0) is non-linear; rectifies negative values
   - I_AMPA_curr = gAMPA * (I_M_a + I_M_v) * (Erev_ampa - v_msi)
   - Erev_ampa is positive (typically 0 or +), v_msi can be < 0 most of time
   - So (Erev - v_msi) is usually positive, I_AMPA_curr positive
   - I_ampa_filtered tracks similar; bare-add of (I_M_a + I_M_v) sparse spike

D) I_ampa_filtered.add_(I_M_a_AMPA + I_M_v_AMPA) (L2066) onto leaky integrator.
   Steady-state mean dt-invariant.  Reach to steady state may differ.

E) Izhikevich Forward Euler.  Smaller dt = more accurate; can affect threshold
   crossing timing differently than dt=0.1.  Previously ruled out by izhi-half
   test (wrong direction for TBW).  Re-test for SBW.

F) Conduction-delay BUFFER FILL phase.  At dt=0.05, more substeps before any
   spike round-trips (delays larger in substeps).  May affect transient onset
   before steady-state — relevant in brief 200 ms SBW window.

G) State-init differences.  reset_state() resets to specific values.  No dt-
   scaling needed in reset.  But the trajectory from init to steady state
   differs over n_substeps steps.

H) MEASUREMENT-level dt dependence:
   - enhancement = sum spikes over duration frames
   - SBW HW depends on sum spikes in ROI
   - Per-substep spike count is dt-dependent (smaller dt = fewer per substep)
   - BUT total spikes per ms is dt-invariant if dynamics are.

PRIORITY (highest-dt-dependence-suspect first):
  1. H_agc       AGC update equation, not dt-scaled, uses raw final I_M.
  2. H_lat_msi   Lateral inh via NEW_sM not buffered spike (L2249).
  3. H_ampa_m    AMPA filtered LP variable behavior.
  4. H_nmda_m    NMDA gating variable in transient regime (already studied; SBW
                  uses 200 ms stim, mostly steady-state, but verify).
  5. H_izhi      Izhikevich Euler integration error (already ruled out for TBW).
  6. H_buffer    Conduction-delay buffer fill transient at finer dt.
  7. H_inh_FF/recur/lat — spike-driven inh paths.  Mean dt-invariant theoretically;
                  empirically test.
